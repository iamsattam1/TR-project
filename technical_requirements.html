02

Overarching requirement: stable text-object IDs and translation-batch IDs

The website backend assigns one ID to each extracted PowerPoint text object and another ID to every planned batch. Both remain traceable through translation, review, revisions and final reconstruction.

Example: batch B-004 contains TXT-S03-O05 and TXT-S03-O06. A finding on O05 references both the object ID and its batch ID; corrected Arabic is inserted back into the original O05 text box. The website backend owns these links—not the language model.

What “document context” means

The context profile should describe the actual document—not assign a generic label such as “to inform.”

Keep Arabic style separate.
The document context profile contains purpose, audience, domain, structure, terms and open questions. Arabic style belongs in the separate style guide and translation/review prompts.
